# Pace – Your Journey, Your Pace 🏃‍♀️


Pace is a Flutter-based weight management application designed to make healthy living simpler, more organized, and sustainable. It helps users track their daily habits, monitor calorie intake, manage hydration, log meals, and visualize their fitness progress through a clean and intuitive interface.

Rather than promoting extreme fitness goals, Pace focuses on building consistent habits and helping users make gradual progress.

### 🔐 Authentication & User Profile

- Google Sign-In.

- User-specific health and fitness information.

## 📱 Application Structure

The application is organized around four primary navigation sections:

1. **Home:** Daily calorie summary, habits, water intake and health overview.
2. **Progress:** Daily and weekly fitness progress.
3. **Calendar:** Historical activity and tracking records.
4. **Me:** User profile, personal information and fitness goals.

## 🚀 Getting Started

### Prerequisites
- Flutter SDK
- Dart SDK
- Android Studio or VS Code
- Firebase account
- Android Emulator or physical Android device

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/your-username/pace.git
```

**2. Navigate to the project directory**

```bash
cd pace_app
```

**3. Install dependencies**

```bash
flutter pub get
```

**4. Configure Firebase**

Connect your Firebase project using FlutterFire CLI:

```bash
flutterfire configure
```

Ensure Firebase Authentication and Cloud Firestore are enabled in your Firebase project.

**5. Run the application**

```bash
flutter run
```
